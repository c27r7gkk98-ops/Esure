VERSION 2 CHANGES
- Administrator logout button added.
- Administrator dashboard now shows all active customer policies.
- Admin form includes vehicle make, model and engine cc.
- Admin can add customers.
- Admin can remove a customer and all stored details and policies.
- FAQ password-reset answer now matches the supplied screen recording exactly.
- Customer and admin accounts share the same FAQ content.

IMPORTANT
This is a browser-only demonstration. Data and passwords are stored locally and are not secure enough for real customers.


VERSION 3 CHANGES
- Fixed policy amount fields so entries such as 382.35, £382.35, and 1,250.00 save correctly.
- Prevented invalid amounts from displaying as NaN.
- Added a live "Days Remaining" figure to every policy card on customer and administrator dashboards.


VERSION 4 CHANGES
- Replaced the previous certificate layout with the uploaded one-page certificate template.
- Customer and vehicle fields now appear over the matching locations in that template.
- Download PDF / Print uses the same certificate appearance.
- The certificate retains a visible private-demo notice and is not valid evidence of insurance.


VERSION 5 CHANGES
- The certificate is now generated as a clean HTML document instead of placing edited-looking text over a screenshot.
- All customer and vehicle details use one consistent font, weight, spacing and alignment.
- The certificate automatically applies to whichever customer is logged in.
- In the admin account, the certificate automatically applies to the customer currently selected in Admin/Profile.
- Printing or saving as PDF keeps the same generated layout.


VERSION 6 — WELCOME EMAIL DEMO
- Added a professional welcome email preview populated from the selected customer and active policy.
- Added “Create Policy & Send Welcome Email” in the administrator panel.
- Added “Preview Welcome Email”.
- Added “Open in Mail App” to prepare a real message in Apple Mail or the default email application.
- Added per-customer email history.
- The browser-only demo records an email as “Demo sent”; it does not send automatically over the internet.
- Real automatic delivery requires secure hosting, a backend, and an email provider.


VERSION 7 — MULTIPLE POLICIES
- Each customer can now hold multiple policies.
- Added “Add Another Policy” and “Remove Selected Policy” to the admin page.
- Added a policy selector for editing the correct customer policy.
- Customer dashboards show active policies first and previous/expired policies below.
- Administrator dashboard shows all active policies first and all previous policies below.
- Opening a policy, certificate, or email preview uses the selected policy.


VERSION 8 — DAYS REMAINING FIX
- Fixed policies incorrectly showing 0 days remaining.
- Added support for UK dates such as 29/07/2026, 29-07-2026 and 29 July 2026.
- Added support for dates containing weekday names, such as Thursday 30 July 2026.
- Days remaining is now inclusive, so a policy expiring today displays 1 day remaining.
- Invalid or incomplete end dates display a dash instead of incorrectly showing 0.


VERSION 9 — AUTOMATIC POLICY EXPIRY
- The portal checks every policy whenever it is opened or refreshed.
- When the end date has passed, the policy status automatically changes from Active to Expired.
- Expired policies automatically move from Active Policies to Previous Policies.
- Active/previous policy counts update automatically.
- Days Remaining becomes 0 for expired policies.
- Added renewal notices at 30, 14, 7 and 1 day before expiry.
- Policies expiring today show “Expires today”.


VERSION 10 — TOTAL PREMIUM SUMMARY
- Profile > Account Summary now adds together the premium from every policy belonging to that customer.
- Added a Premium Breakdown showing each policy and its premium amount.
- Added a final Total of all policy premiums.
- The calculation updates automatically whenever policies are added, removed or edited.


VERSION 11 — EMAIL FEATURE REMOVED
- Removed the welcome email preview.
- Removed “Create Policy & Send Welcome Email”.
- Removed “Open in Mail App”.
- Removed per-customer email history.
- Admin customer and policy management remains unchanged.
